# 🤖 Bot Feriados Discord

Um bot de Discord desenvolvido em **TypeScript** e **Node.js** que consome a **Brasil API** para fornecer informações em tempo real sobre os feriados nacionais, além de calcular contagens decrescentes inteligentes para as próximas festividades.

---

## 🚀 Funcionalidades

* **`/feriados`**: Lista todos os feriados nacionais do ano corrente com avisos especiais (como para o período de Natal).
* **`/proximo-feriado`**: Mostra exatamente qual é o próximo feriado nacional e quantos dias faltam para lá chegar, com contagem decrescente em tempo real.
